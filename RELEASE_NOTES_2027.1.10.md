# StageDesk 2027.1.10 — parcours de conversion / conversion workflow

## Français

Ouvrez une source console, logiciel ou tableau, ou reprenez une préparation StageDesk / un projet StageFlow ; modifiez si besoin, puis convertissez vers la destination choisie. L’étape de conversion distingue **Créer un nouveau projet**, **Créer un snapshot / une scène**, **Insérer dans un projet existant**. Chaque option suit les modes et sélections réellement disponibles pour le modèle et le projet reconnus.

L’aperçu affiche le projet et l’état/scène cibles, ce qui sera ajouté ou mis à jour et les données conservées dans la préparation. Une modification de la demande pendant cet aperçu impose une nouvelle vérification. Les formats, adaptateurs, mappings, PatchSets, outils, cases Inclure / Appliquer, confirmations, sauvegardes et licences restent conservés. Les transferts réseau gardent leurs commandes explicites et leurs limites ; aucun nouveau protocole ni conversion complète de show n’est annoncé.

Pour CL/QL, l’aperçu précise que la création d’une scène actualise Current avant de le dupliquer dans le nouveau slot ; les autres scènes enregistrées sont conservées. Ce comportement du convertisseur existant n’est pas modifié.

Windows : livraison après recette et remplacement sauvegardé par l’atelier. Mac : préparation prévue pour le 1er novembre dans le quota gratuit, qualification et publication distinctes ; les anciens DMG ne valident pas cette interface.

## English

Open a console, software or table source, or resume a StageDesk preparation / StageFlow project; edit if needed, then convert to the chosen destination. The conversion step distinguishes **Create a new project**, **Create a snapshot / scene**, and **Insert into an existing project**. Each option follows the modes and selections actually available for the recognised model and project.

The preview identifies the target project and state/scene, what will be added or updated, and data retained in the preparation. Changes to the request while this preview is open require another review. Formats, adapters, mappings, PatchSets, tools, Include / Apply selections, confirmations, backups and licensing are preserved. Network transfers retain explicit commands and existing limits; no new protocol or full-show conversion is claimed.

For CL/QL, the preview clarifies that creating a scene updates Current before duplicating it into the new slot; other stored scenes are preserved. This existing converter behaviour is unchanged.

Windows delivery follows workshop qualification and a backed-up replacement. Mac preparation is scheduled for the free-quota follow-up on 1 November; native qualification and publication remain separate. Earlier DMGs do not qualify this interface.
