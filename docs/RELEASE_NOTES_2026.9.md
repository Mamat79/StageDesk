# StageDesk v2026.9

## Français

Cette version fait entrer définitivement l’application dans la suite SiLeMI/O
sous son nom public unique **StageDesk**.

### Ce qui change

- interfaces Windows, aide, notices, documents et livrables renommés StageDesk ;
- projets autonomes `.smtshow`, projets partagés `.stageflow`, anciens fichiers
  `.smt` et toutes les fonctions de transfert existantes conservés ;
- noms proposés pour les nouveaux projets, tableaux et exports alignés sur
  StageDesk ;
- mise à jour sécurisée depuis le nouveau dépôt public `Mamat79/StageDesk` ;
- repli strict vers l’ancien dépôt `Save-My-Time-SMT` uniquement lorsqu’il est
  nécessaire aux versions déjà installées ;
- paquet principal `StageDesk-v2026-win-x64.zip` et alias binaire identique
  `SMT-v2026-win-x64.zip` pour la continuité des mises à jour 2026.8 ;
- paquets natifs autonomes pour macOS Intel (`osx-x64`) et Apple Silicon
  (`osx-arm64`), sous le même nom StageDesk ;
- liens et présentations harmonisés avec StageFlow, Dante Config Editor,
  StageMark et StageMon.

Les identifiants internes indispensables aux projets, aux licences et aux
installations existantes restent inchangés. La licence, les préférences et les
projets utilisateur sont donc retrouvés automatiquement après la mise à jour.

## English

This release permanently brings the application into the SiLeMI/O suite under
its single public name, **StageDesk**.

### What changes

- Windows interfaces, help, manuals, documentation, and deliverables now use
  the StageDesk name;
- standalone `.smtshow` projects, shared `.stageflow` projects, legacy `.smt`
  files, and every existing transfer feature are preserved;
- suggested names for new projects, tables, and exports now use StageDesk;
- secure updates prefer the new public `Mamat79/StageDesk` repository;
- the legacy `Save-My-Time-SMT` repository is used only as a strict fallback
  for already-installed versions;
- the primary `StageDesk-v2026-win-x64.zip` package is accompanied by a
  byte-identical `SMT-v2026-win-x64.zip` compatibility alias for 2026.8;
- self-contained native packages are also provided for macOS Intel (`osx-x64`)
  and Apple Silicon (`osx-arm64`) under the same StageDesk name;
- cross-suite links and presentations are aligned with StageFlow, Dante Config
  Editor, StageMark, and StageMon.

Internal identifiers required by existing projects, licences, and installed
versions remain unchanged. The update therefore keeps the user's licence,
preferences, and projects in place.
