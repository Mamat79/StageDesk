# StageDesk v2027

Version Windows : 2027.0.4.

## Français

- Le nom public est désormais **StageDesk** partout dans les documents livrés,
  les exemples, la page d’achat et les métadonnées publiques.
- L’ancien sous-titre n’est plus affiché comme une marque active.
- Un contrôle automatisé empêche son retour dans les surfaces publiques et
  vérifie que l’abréviation historique n’est pas employée comme nom de produit.
- La page d’achat StageDesk a été redéployée avec le nom public unique.

Les identifiants nécessaires à la compatibilité restent inchangés : projets
`.smt` et `.smtshow`, domaine `smt/smt.json`, codes de licence, identifiant
d’application, alias de mise à jour et canal historique. Aucune fonction métier,
aucun projet utilisateur et aucun réglage ne sont modifiés par ce correctif.

La version publique macOS reste 2027.0.2 pour Intel et Apple Silicon jusqu’à
une future compilation et recette natives.

[Télécharger pour votre système](https://www.silemio.com/logiciels/stagedesk)

## English

- The public product name is now **StageDesk** throughout bundled documents,
  examples, the purchase page and public metadata.
- The former subtitle is no longer presented as an active brand.
- An automated contract prevents its return on public surfaces and ensures the
  historical abbreviation is not used as the product name.
- The StageDesk purchase page has been redeployed with the single public name.

Compatibility identifiers remain unchanged: `.smt` and `.smtshow` projects,
the `smt/smt.json` domain, license codes, application identifier, update alias
and historical channel. This maintenance release changes no product feature,
user project or setting.

The public macOS version remains 2027.0.2 for Intel and Apple Silicon until a
future native build and acceptance.

[Download for your system](https://www.silemio.com/en/software/stagedesk)
