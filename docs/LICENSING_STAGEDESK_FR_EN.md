# Licences StageDesk / StageDesk licensing

## Français

**Windows.** Choisissez **Continuer avec StageDesk** pour utiliser toutes les fonctions pendant 30 jours, même hors ligne. Une réinstallation sous le même compte Windows conserve la date de départ. StageDesk synchronise l’essai lors d’un démarrage connecté. Après l’essai, le prochain démarrage demande une licence. Les projets enregistrés restent sur le disque.

**macOS.** Choisissez **Continuer avec StageDesk** pour utiliser gratuitement toutes les fonctions, y compris hors ligne. L’activation d’un nouveau code de licence est disponible sur Windows.

### Licence Windows

La licence permanente Windows coûte **49 € TTC**. Le code acheté ou offert s’active en ligne, puis l’application fonctionne hors ligne. La fenêtre Licence indique le nombre de postes autorisés pour votre code. Pour transférer un poste, utilisez **Désactiver cet ordinateur** sur l’ancien ordinateur connecté, puis activez le nouveau.

Les licences déjà activées conservent les droits associés à leur code. Les mises à jour qui conservent le profil de l’application préservent aussi l’activation. [Boutique SiLeMI/O](https://www.silemio.com/acheter)

## English

**Windows.** Choose **Continue with StageDesk** to use every feature for 30 days, including offline. Reinstalling under the same Windows account preserves the start date. StageDesk syncs the trial when launched with internet access. After the trial, the next launch requires a license. Saved projects stay on disk.

**macOS.** Choose **Continue with StageDesk** to use every feature for free, including offline. New license code activation is available on Windows.

### Windows license

A permanent Windows license costs **€49 including tax**. Activate a purchased or complimentary code online, then use the application offline. The license window shows the installation limit for your code. To transfer a seat, select **Deactivate this computer** on the old computer while connected, then activate the new computer.

Existing activations retain the rights granted by their code. Updates that preserve the application profile also keep activation. [SiLeMI/O store](https://www.silemio.com/acheter)
