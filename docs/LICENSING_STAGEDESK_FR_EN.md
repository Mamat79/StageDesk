# Licences StageDesk / StageDesk licensing

**Save My Time**

## Français

### Ce qui ne change jamais

StageDesk n’est pas bloqué à la fin de l’essai. Les 30 premiers jours sont sans
rappel. Ensuite, une fenêtre de démarrage reste visible pendant 10 secondes,
mais toutes les fonctions et tous les fichiers restent accessibles. Une licence
permanente supprime uniquement ce rappel.

### Achat

Le bouton **Acheter une licence — 29 € TTC** ouvre la page Stripe officielle.
Après l’achat, la page de confirmation fournit le code à saisir dans StageDesk.
StageDesk ne reçoit aucune donnée bancaire.

### Activations

Une licence autorise 3 installations par défaut. La première activation demande
une connexion Internet. Ensuite, StageDesk peut valider la licence hors ligne.

La fenêtre de licence affiche le nombre d’installations utilisées et autorisées.
Le bouton **Désactiver cet ordinateur** libère une place puis retire uniquement
l’activation locale. StageDesk et les projets restent utilisables.

## English

### What never changes

StageDesk is not locked when the trial ends. The first 30 days have no reminder.
Afterwards, a startup window remains visible for 10 seconds, but every feature
and file remains available. A permanent license only removes that reminder.

### Purchase

**Buy a license — €29 including tax** opens the official Stripe page. After a
purchase, the confirmation page provides the code to enter in StageDesk.
StageDesk receives no bank details.

### Activations

A license allows 3 installations by default. Initial activation requires an
Internet connection. StageDesk can then validate the license offline.

The license window shows the used and allowed installation counts.
**Deactivate this computer** releases a seat and removes only the local
activation. StageDesk and its projects remain usable.
