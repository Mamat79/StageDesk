# Licences StageDesk / StageDesk licensing

## Français

### Utiliser gratuitement, sans code et sans Internet

Pour essayer ou utiliser StageDesk gratuitement, aucun code ni activation en
ligne n’est requis. Dans la fenêtre **Essai gratuit et licence StageDesk**,
choisissez **Continuer avec StageDesk**. Le champ de code est facultatif :
laissez-le vide si vous n’avez pas de licence permanente achetée ou offerte.
L’utilisation gratuite fonctionne aussi hors ligne.

### Ce qui ne change jamais

StageDesk n’est pas bloqué à la fin de l’essai. Pendant les 30 premiers jours,
un rappel d’achat au démarrage est refermable immédiatement. Ensuite, la fenêtre
reste visible pendant 5 secondes au démarrage uniquement, puis toutes les
fonctions et tous les fichiers restent accessibles. Elle n’interrompt jamais
une session ou un travail en cours. Une licence permanente valide supprime le
rappel et l’attente.

### Achat

Sur macOS, l’activation d’un nouveau code de licence permanente n’est pas prise
en charge dans cette version. N’achetez pas un code pour l’activer sur Mac en
vous fondant sur ce parcours. L’utilisation gratuite reste disponible, sans code
ni Internet, avec **Continuer avec StageDesk**. Cette mise à jour ne modifie pas
les droits ni les licences existantes et n’ajoute pas de mécanisme d’activation Mac.

Le bouton **Acheter une licence sur le site officiel** ouvre la
[page d’achat SiLeMI/O](https://www.silemio.com/acheter). La licence permanente
StageDesk coûte **99 € TTC**. Après l’achat, la page de confirmation fournit le
code à saisir dans StageDesk. StageDesk ne reçoit aucune donnée bancaire.

### Activer un code de licence permanente achetée ou offerte

Une licence autorise 3 installations par défaut. La première activation demande
une connexion Internet pour ce code ; elle n’est pas nécessaire pour utiliser
StageDesk gratuitement. Ensuite, StageDesk peut valider la licence hors ligne.
Si la connexion échoue, le code n’est pas activé et l’utilisation gratuite reste
possible avec **Continuer avec StageDesk**, après le délai habituel s’il s’applique.

La fenêtre de licence affiche le nombre d’installations utilisées et autorisées.
Le bouton **Désactiver cet ordinateur** libère une place puis retire uniquement
l’activation locale. StageDesk et les projets restent utilisables.

## English

### Use for free, without a code or Internet

To try or use StageDesk for free, no code or online activation is required.
In the **StageDesk free trial and license** window, choose **Continue with
StageDesk**. The code field is optional: leave it empty if you do not have a
purchased or complimentary permanent license. Free use also works offline.

### What never changes

StageDesk is not locked when the trial ends. During the first 30 days, the
startup purchase reminder can be closed immediately. Afterwards, the window
remains visible for 5 seconds at startup only, then every feature and file
remains available. It never interrupts an active session or work in progress.
A valid permanent license removes both the reminder and the delay.

### Purchase

On macOS, activating a new permanent license code is not supported in this
version. Do not purchase a code expecting to activate it on Mac through this
workflow. Free use remains available without a code or Internet through
**Continue with StageDesk**. This update does not change existing rights or
licenses and does not add a Mac activation mechanism.

**Buy a license on the official website** opens the
[SiLeMI/O purchase page](https://www.silemio.com/acheter). A permanent StageDesk
license costs **€99 including tax**. After a purchase, the confirmation page
provides the code to enter in StageDesk. StageDesk receives no bank details.

### Activate a purchased or complimentary permanent license code

A license allows 3 installations by default. Initial activation requires an
Internet connection for that code; this is not required to use StageDesk for
free. StageDesk can then validate the license offline. If the connection fails,
the code is not activated and free use remains available through **Continue
with StageDesk**, after the usual delay if applicable.

The license window shows the used and allowed installation counts.
**Deactivate this computer** releases a seat and removes only the local
activation. StageDesk and its projects remain usable.
