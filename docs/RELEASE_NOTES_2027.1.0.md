# StageDesk 2027.1.0 — notes de version / release notes

## Français

- StageDesk protège désormais automatiquement les modifications non
  enregistrées dans une copie de récupération atomique et indépendante du
  projet d’origine. Au lancement suivant, cette copie peut être restaurée comme
  projet autonome, supprimée explicitement ou conservée en quittant.
- Le centre Connexion StageFlow se réorganise sur une seule colonne dans les
  petites fenêtres, conserve le défilement et reste utilisable jusqu’à
  640 x 360 DIP sans réduire les textes.
- Le rappel de licence suit le nouveau contrat commun : pendant l’essai de
  30 jours il est refermable immédiatement ; après l’essai, il affiche un
  décompte monotone de 60 secondes au démarrage uniquement, puis StageDesk
  reste entièrement utilisable. Une activation valide supprime immédiatement
  le rappel et l’attente.
- Les licences existantes, reçus hors ligne, projets, réglages et données LIVE
  sont préservés. Aucune attente n’est ajoutée pendant une session ou lors d’un
  changement de projet.

## English

- StageDesk now protects unsaved changes automatically in an atomic recovery
  copy that is independent from the original project. On the next launch, this
  copy can be restored as a standalone project, explicitly deleted, or kept by
  quitting.
- The StageFlow connection center reflows to one column in small windows,
  retains scrolling, and remains usable down to 640 x 360 DIP without reducing
  text sizes.
- The license reminder follows the new shared contract: during the 30-day trial
  it can be closed immediately; after the trial, it shows a monotonic 60-second
  countdown at startup only, then StageDesk remains fully usable. A valid
  activation immediately removes both the reminder and the delay.
- Existing licenses, offline receipts, projects, settings and LIVE data are
  preserved. No delay is added during a session or when switching projects.

Windows and macOS packages require their respective final acceptance before
publication. Network workflows remain voluntary and never trigger a console or
DAW transfer implicitly.
