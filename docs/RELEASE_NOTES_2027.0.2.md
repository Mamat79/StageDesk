# StageDesk v2027

Version 2027.0.2 - Windows x64, macOS Intel et Apple Silicon.

## Français

- Le simple affichage du tableau conserve les couleurs et les icônes, y compris
  les valeurs personnalisées. Un défaut de sélection pouvait auparavant les
  vider lors de la création visuelle des cellules.
- Les commandes PatchSet partagent une barre compacte : même sur une petite
  fenêtre, les premières lignes restent visibles et le tableau peut s'agrandir.
- La recherche de mises à jour trouve la version stable la plus récente adaptée
  à Windows, à un Mac Intel ou à un Mac Apple Silicon, même si le dernier
  correctif d'une autre plateforme porte un numéro différent.
- Seules les publications avec le bon installateur et son fichier SHA-256 sont
  proposées. Le fichier téléchargé est contrôlé avant d'être présenté ;
  l'installation reste une décision de l'utilisateur.
- Le bandeau compact et la navigation latérale lisible sont réunis dans cette
  version commune Windows et Mac. Les panneaux restent repliables pour agrandir
  le tableau, en français comme en anglais.
- Les notices StageDesk et les guides communs SiLeMIO 2027.1 sont inclus en
  français et en anglais, avec les parcours autonomes, StageFlow local et LIVE.
- Le contrôle global ouvre effectivement les panneaux repliés et renvoie leur
  état actualisé. Les commandes déjà reçues ne sont pas rejouées ; un résultat
  expiré est signalé sans nouvel essai automatique.

Les projets, réglages, activations et connecteurs existants restent compatibles.
Sous Windows, l'installateur remplace StageDesk dans son emplacement habituel.
Les DMG Mac utilisent une signature d'intégrité ad hoc, sans signature Developer ID
ni notarisation Apple. Ne désactivez pas les protections de macOS.

[Télécharger pour votre système](https://www.silemio.com/logiciels/stagedesk)

## English

- Displaying the table preserves colours and icons, including custom values.
  A selection-binding defect could previously clear them when cells were
  created on screen.
- PatchSet commands share a compact toolbar, keeping the first rows visible
  in a small window while allowing the table to expand.
- Update checks find the highest stable version matching Windows, Intel Mac or
  Apple Silicon Mac, even when another platform's latest fix has a different
  version number.
- Only releases containing the correct installer and its SHA-256 file are
  offered. The download is verified before it is presented; installation
  remains the user's decision.
- This shared Windows and Mac release includes the compact header and readable
  sidebar. Panels remain collapsible to expand the table in French and English.
- French and English StageDesk manuals and the common SiLeMIO 2027.1 guides are
  included, covering standalone work, local StageFlow projects and LIVE sessions.
- Global control reveals collapsed panels and returns current state. Previously
  received commands are not replayed; expired results are reported without an
  automatic retry.

Existing projects, settings, activations and connectors remain compatible.
On Windows, the installer replaces StageDesk in its usual location.
Mac DMGs use ad-hoc integrity signing, without Apple Developer ID signing or
notarization. Do not disable macOS security protections.

[Download for your system](https://www.silemio.com/en/software/stagedesk)
