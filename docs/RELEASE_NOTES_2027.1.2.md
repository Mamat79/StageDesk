# StageDesk 2027.1.2

## Français

- Corrige l’export vers Yamaha CL/QL lorsqu’un label raccourci se terminait par un espace, notamment « Guitare jardin » au canal 15.
- Normalise les espaces de fin avant l’écriture afin d’éviter les fausses erreurs de relecture sur les consoles utilisant des champs de labels de longueur fixe.
- Vérifie le correctif sur les modèles CL3 et CL5 et protège tous les profils de destination acceptant des labels.

## English

- Fixes Yamaha CL/QL export when a shortened label ended with a space, including “Guitare jardin” on channel 15.
- Normalizes trailing whitespace before writing to prevent false readback errors on consoles using fixed-width label fields.
- Verifies the fix with CL3 and CL5 and protects every destination profile that accepts labels.
